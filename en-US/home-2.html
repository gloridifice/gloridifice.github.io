An Overview of the Bevy Engine's Rendering Architecture

This article briefly introduces Bevy's rendering architecture, including the directed acyclic graph that manages rendering order, System ordering in the rendering workflow, render phases for different objects, and interactions between the main world and the render world. It uses Bevy Core 3D's rendering implementation as a reference. It also briefly covers how to use Bevy's rendering APIs in everyday development.
